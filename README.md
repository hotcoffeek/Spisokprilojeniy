# Список приложений (RecentsTV)

Плитки недавних приложений для Android TV. Открывается по выбранной кнопке пульта.
OK — открыть, ↑ — закрыть выбранное, ↓ — крестик «закрыть всё».

## Установка и настройка (без ADB)

1. Установите `RecentsTV.apk` любым способом.
2. Запустите «Список приложений: настройка».
3. Шаг 1 — включите службу специальных возможностей «Список приложений».
   Если переключатель серый: Сведения о приложении → ⋮ → «Разрешить ограниченные настройки».
4. Шаг 2 — нажмите «Назначить кнопку» и нажмите любую свободную кнопку пульта.

Дальше эта кнопка открывает (и закрывает) список поверх любого приложения.

## Сборка

Заливаете проект на GitHub: вкладка Actions → Build APK → артефакт `RecentsTV-apk`.
